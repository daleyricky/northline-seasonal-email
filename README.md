
# NORTHLINE ATHLETICS
## The Winter Training Edit

### Project overview

A fictional seasonal email campaign created for NORTHLINE
ATHLETICS, a premium performance apparel brand.

The campaign introduces a cold-weather training collection
using an editorial visual style and a direct shopping CTA.

### Objective

Design and develop a responsive promotional email that:

- Introduces a seasonal apparel collection.
- Highlights three featured products.
- Encourages customers to visit the collection.
- Provides a consistent experience across desktop and mobile.

### My responsibilities

- Email design and layout.
- HTML email development.
- Responsive styling.
- Image optimization and accessibility.
- Quality assurance and documentation.

### Technical approach

- HTML5
- Table-based email layout
- Inline CSS
- Responsive media queries
- Semantic content and image alt text

### Deliverables

- Responsive HTML email
- Image assets
- Desktop and mobile screenshots
- QA test report

### Project status

Portfolio concept — fictional brand and campaign.
No real products, customers or sales results are represented.

### Future improvements

- Test in Gmail, Outlook and Apple Mail.
- Replace demo links with production URLs.
- Host images on an HTTPS asset server.
- Add campaign tracking parameters.
- Validate final markup with an email-specific testing tool.
